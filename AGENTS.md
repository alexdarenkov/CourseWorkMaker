# AGENTS.md — CourseWorkMaker (md2docx)

Файл-указатель для AI-агентов. Этот файл намеренно короткий — не дублируй
содержимое сюда, правь первоисточники.

**CourseWorkMaker** — веб-приложение для написания и оформления курсовых
работ по ГОСТ 7.32-2017: Markdown-редактор, живое постраничное превью
«как в Word», серверный экспорт в DOCX, ИИ-генерация. Документация,
комментарии и UI — на русском.

## Главные правила

1. Меняя поведение — правь `CLAUDE.md` в том же изменении, если меняется
   инвариант или устройство, описанное там.
2. Превью и DOCX — два параллельных рендера: правки диалекта/оформления
   вносятся на ОБЕ стороны (`frontend/src/lib/` ↔ `services/backend/app/convert/`)
   с тестами обеих сторон.
3. Стиль кода: минимальные изменения, следуй стилю файла; комментарии
   и сообщения об ошибках — на русском.
4. Существующую логику тестов не менять — исправлять только поломки
   от изменения интерфейсов.
