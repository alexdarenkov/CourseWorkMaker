# Приведение Markdown к правилам оформления

Статус: запланировано, после согласования правил исправления.

Добавить кнопку «Привести к ГОСТ», которая по явному действию пользователя изменяет исходный Markdown в соответствии с выбранными правилами приложения. Включить пунктуацию перечислений и пояснений, конечные точки заголовков и подписей, другие согласованные исправления, требующие изменения исходного текста.

- Обычный рендер и экспорт не должны незаметно переписывать исходный Markdown.
- Исправления должны сохранять смысл текста, код, формулы и ссылки на ассеты; повторное применение к уже исправленному тексту не должно создавать новые изменения.
- Предусмотреть просмотр изменений и возможность отменить исправление.
- Неоднозначные случаи не исправлять догадкой: показывать пользователю, что требует решения. Конкретные правила диагностики и исправления описать перед реализацией.
- Будущий ИИ-агент должен уметь вызывать ту же функциональность; общие правила исправления не дублировать отдельно в агенте.
- Перед реализацией обновить спецификации Markdown, работы с документом и интерфейса; проверить сохранность исходного содержимого, отмену, повторное применение и одинаковую интерпретацию результата в превью и DOCX.
