# Явное обозначение структурных заголовков

Статус: обсуждается, новый синтаксис не принят.

Вариант: `#` обозначает структурный элемент, `##` — раздел, `###` — подраздел, `####` — пункт. Нумеруемых уровней остаётся три.

Преимущество: тип заголовка определяется синтаксисом, а не совпадением начала названия со словарём. Обычный раздел «Список методов» можно отличить от структурного элемента «Список использованных источников».

До принятия определить:

- Совместимость с существующим диалектом, в котором `#` также обозначает нумеруемый раздел; нельзя молча менять смысл старых документов при импорте и восстановлении.
- Как определять вид структурного элемента: реферат, содержание, библиография и другие имеют разное поведение. Сам по себе `#` этого не задаёт.
- Обработку пропусков уровней и более глубоких заголовков.
- Альтернативу: отдельную явную пометку структурного элемента с сохранением `#`–`###` для нумеруемых заголовков.

После выбора обновить спецификацию диалекта, оба парсера, связанные функции редактора, тесты и при необходимости ADR.
