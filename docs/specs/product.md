# Работа с документом

Подробности предложены для обсуждения. [Общие принятые правила](core.md) сохраняются.

## Сценарий редактирования

Аккаунтов нет. Пользователь пишет Markdown, видит превью,
меняет настройки и скачивает DOCX. AI-сценариев нет.

Настройки документа: titlePage, toc, pageNumbers, bibliography, autoNumber;
по умолчанию включены. Поля титульника задаются отдельно.
Кегль моноширинного шрифта редактора — 11…16 px с шагом 1, по умолчанию 13 px;
значение прежней шкалы 12…18 px из старых сохранений приводится к границе диапазона.
Тема интерфейса, размер шрифта редактора, переносы и подсветка не меняют стиль DOCX.
Пример: шрифт редактора 16 pt → основной текст DOCX остаётся 14 pt.

## Сохранность и импорт

Документ хранится в профиле браузера.
Автосохранение — через 700 мс. При ошибке показываем «Повторить»;
несохранённый текст не выдаём за сохранённый.
Переход на главную и смена темы сохраняют несохранённый черновик в памяти:
настройки применяются к нему, а не к устаревшей копии localStorage.
Поддерживаются Markdown и ZIP. Архив переносит текст, настройки и локальные рисунки.
Внешние рисунки сам не скачивает. Кнопки экспорта ZIP сейчас нет.

Пример: ссылка на изображение внутри листинга не изменяется при импорте.
Подробные ограничения сохранности — в [общих правилах](core.md).

## Отмена редактирования

В Chrome вставка из тулбара, Tab, Ctrl/Cmd+B и Ctrl/Cmd+I входят в native Undo:
Ctrl/Cmd+Z отменяет вставку без потери предшествующего текста, Redo возвращает её.
Проверять в реальном браузере: happy-dom не реализует native undo-стек.

## Экспорт

Успешный экспорт скачивает DOCX. Ошибка сохраняет текст и позволяет повторить действие.
Проверяем успешный экспорт, 429 и 500.

Вид экранов — в [ui-ux.md](ui-ux.md), запросы — в [api.md](api.md).
