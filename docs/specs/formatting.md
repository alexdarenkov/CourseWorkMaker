# Оформление DOCX

Все правила, источники, примеры и расхождения собраны в
[правилах оформления документа](../reference/formatting-rules.md).
Редактируем их там, не создаём вторую копию в этом файле.

Свод пока на согласовании. Источником обязательного поведения становятся только
явно принятые правила; наличие поведения в коде не означает принятия.
Ранее согласованные обязательства — в [core.md](core.md).

После согласования пункта обновляем код и тесты обеих сторон.
Порядок проверки — в [verification.md](verification.md).
