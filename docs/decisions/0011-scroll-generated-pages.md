# ADR-0011: прокрутка через сгенерированные страницы

Статус: принят. Дата исходного решения: 2026-09-12.
Изложение обновлено 2026-09-13 без изменения решения.

## Контекст

Титульник и содержание не имеют строк Markdown. Содержание может находиться
между рефератом и введением; простая интерполяция якорей двигает редактор,
когда пользователь просматривает эти страницы.

## Решение

Page.generated помечает title/toc. Синхронизация исключает их высоту и зазор
после них из координат интерполяции, затем переводит результат в физическую ленту.
Общая карта исходных якорей используется также маркером каретки.
Позиция после пересчёта хранится как строка исходника либо положение внутри
сгенерированного раздела. Наблюдаемое поведение определено [Синхронная прокрутка](../specs/core.md#синхронная-прокрутка).

## Альтернативы и последствия

Виртуальные блоки в редакторе потребовали бы замены/усложнения textarea.
Выбранный вариант сохраняет обычный Markdown, но требует согласованной геометрии
страниц и отдельной обработки границ сгенерированных разделов.
Изменения пагинации проверяются вместе с scrollSync и caret. DOCX от этого
решения не зависит. См. architecture/flows/document.md.
