# ADR-0013 Публикация MVP на VPS

Статус: предложен для первого публичного развёртывания.

## Контекст

Нужно опубликовать существующий Docker Compose с публичным конвертером.
Провайдер и домен ещё не выбраны. TLS и ограничения запросов требуются ADR-0012.

## Решение

Подготовлена самостоятельная production-конфигурация: Caddy завершает TLS,
nginx отдаёт frontend и ограничивает экспорт, FastAPI работает во внутренней
сети без опубликованного порта. Caddy имеет фиксированный внутренний IP для
строгого доверия X-Forwarded-For. Серверное хранение документов не добавляется.

Контейнеры имеют лимиты ресурсов, restart policy и ротацию логов. Backend
запускается непривилегированно с read-only filesystem и временным tmpfs.
Конфигурация не привязана к конкретному российскому VPS-провайдеру.

## Альтернативы

Nginx + Certbot подходит при уже настроенном серверном TLS; для чистого VPS
Caddy сокращает отдельную настройку выпуска/обновления сертификатов.
Managed containers подходят при необходимости масштабирования и управляемой
инфраструктуры, но добавляют стоимость и отдельные контракты сети/лимитов.

## Последствия

Владелец отвечает за обновления VPS, мониторинг и backup конфигурации.
Данные пользователей остаются в браузере, поэтому backup сервера не защищает
их черновики. Домен выбирается до запуска: изменение origin не переносит localStorage.
Подсеть доверенного прокси должна быть согласована с окружением сервера.
Проверка настоящего TLS возможна только после выбора домена и настройки DNS.
