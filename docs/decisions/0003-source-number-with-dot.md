# ADR-0003: Номер источника с точкой

Дата: 2026-07-13
Статус: действует

## Контекст

ГОСТ 7.32-2017 (выписка 6.16) предписывает нумерацию списка источников
арабскими цифрами БЕЗ точки. Нормоконтроль вуза требует номер С точкой.

## Решение

Номер записи в списке источников — «1.» (с точкой, без скобки), с абзацного
отступа, вёрстка как у обычного текста (не висячая).

## Альтернативы

- «1» без точки (по букве ГОСТ) — отвергнуто: требование вуза важнее выписки
  стандарта.
- «1)» со скобкой (как в обычных нумерованных списках) — не соответствует
  ни ГОСТ, ни требованию вуза.

## Последствия

- Реализация: `gostRender.ts` ↔ `gost.py` (комментарии «номер С ТОЧКОЙ»).
- Спека: MD-11 (`specs/markdown-dialect.md`).
- Если другой вуз потребует иначе — это кандидат в настройку документа,
  а не хардкод; оформить новым ADR.
