# ADR-0010: локальные документы и модульный монолит

Статус: принят. Дата исходного решения: 2026-09-11.
Изложение обновлено 2026-09-13 без изменения решения.
Часть про auth, таблицу users и JWT на экспорте заменена [ADR-0012](0012-no-accounts.md).

## Контекст

Первая версия сосредоточена на редактировании и экспорте. Архив AI-прототипа
сохранён отдельно; возвращение AI не является частью текущего MVP.

## Решение

React frontend и один FastAPI backend с модулями auth/convert. Документ и assets
хранятся локально; серверная БД содержит пользователей. Экспорт DOCX требует JWT.
ZIP остаётся механизмом переносимости; доступность действия в UI определяется
[Доступ к редактору и экспорту](../specs/core.md#доступ-к-редактору-и-экспорту), [Переносимый ZIP](../specs/core.md#переносимый-zip), а не этим ADR. Отдельные Java/converter-сервисы не вводятся.

## Альтернативы и последствия

Отдельный сервис полезен при независимом масштабировании или жизненном цикле,
но добавляет сетевые контракты и частичные отказы. Серверное хранение полезно
для нескольких устройств, но требует модели доступа и миграций.
Текущее решение оставляет ограничения localStorage, общий документ для профиля
браузера и отсутствие синхронизации между устройствами. Пересмотреть при появлении
соответствующей продуктовой задачи. Контракт: [Доступ к редактору и экспорту](../specs/core.md#доступ-к-редактору-и-экспорту), [Автосохранение и ошибки записи](../specs/core.md#автосохранение-и-ошибки-записи), [Переносимый ZIP](../specs/core.md#переносимый-zip) в specs/core.md.
