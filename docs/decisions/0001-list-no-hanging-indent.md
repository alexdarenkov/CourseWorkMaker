# ADR-0001: Списки без висячего отступа

Дата: 2026-07 (день не зафиксирован; решение восстановлено из CLAUDE.md при миграции на SDD)
Статус: действует

## Контекст

Изначально пункты списков верстались с висячим отступом: маркер на 1,25 см,
текст и его продолжение — на 2 см. Нормоконтроль вуза ожидает вёрстку пункта
«как обычный абзац с красной строки».

## Решение

Пункт списка — обычный абзац с красной строки: маркер («–» или «N)») на
абзацном отступе 1,25 см, после маркера NBSP, продолжение длинного пункта
переносится к левому полю. Висячего отступа нет.

## Альтернативы

- Висячий отступ (текст на 2 см) — был реализован и ОТКАЧЕН по требованию
  пользователя. Не реализовывать снова.

## Последствия

- DOCX: `first_line_indent=INDENT` без `left_indent` и без табов (`_list` в `gost.py`).
- Превью: `text-indent:12.5mm` без `padding-left` (`renderAll` в `gostRender.ts`).
- Спека: MD-10 (`specs/markdown-dialect.md`).
