# Глоссарий

- **ГОСТ** — здесь ГОСТ 7.32-2017 «Отчёт о научно-исследовательской работе. Структура и правила оформления».
- **Методичка** — присланные рекомендации НИУ ВШЭ 2023 года. Дополняют ГОСТ, но не заменяют его.
- **Структурный элемент** — часть отчёта: например, реферат, введение или заключение.
- **Раздел, подраздел, пункт** — уровни основного текста, например 1, 1.1, 1.1.1.
- **Абзац** — отдельный текстовый блок. Перенос строки внутри него не начинает новый абзац.
- **Красная строка** — отступ первой строки абзаца.
- **Свободная строка** — пустая строка в готовом документе; её не следует путать с разделителем блоков Markdown.
- **Листинг** — блок программного кода в документе.
- **Превью** — вид документа в браузере до скачивания DOCX.
- **Пагинация** — разбиение текста на страницы.

Это пояснения для проекта, не дословные определения стандарта.
