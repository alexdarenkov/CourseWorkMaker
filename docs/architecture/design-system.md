# Как менять дизайн Texturn

## Файлы

- `frontend/src/styles/tokens.css` — цвета светлой и тёмной тем, семейства и основные размеры шрифтов, скругления, высоты контролов, тени, скорость анимаций.
- `frontend/src/styles/components.css` — внешний вид общих элементов: кнопок, полей, карточек, переключателей, сообщений и модальных окон.
- `frontend/src/components/ui.tsx` — React-компоненты и доступность: подписи полей, состояния кнопок, фокус в окне.
- `frontend/src/styles/texturn.css` — оболочка актуального макета: главная, ASCII-фон и полосы заголовков окон. `AsciiBackdrop.tsx` рисует декоративный узор на canvas: он обходит блоки с атрибутом `data-ascii-clear` и перерисовывается только при изменении размеров или темы, без анимационного цикла.
- `frontend/src/index.css` — подключение стилей, базовые правила, скроллбары и эффекты редактора.
- `frontend/tailwind.config.js` — классы Tailwind ссылаются на те же переменные темы.

## Палитра

Синий акцент — прежний Texturn (`#117dff`, кнопки `#2f6fe0`) в обеих темах.
Нейтральные цвета светлой темы — посередине между тёплыми Texturn и
холодными терминальными (фон `#f9f9f8`, текст `#64635c`); тёмной — холодная
терминальная палитра (фон `#0b0e13`). Подсветка редактора использует терминальную (ANSI) палитру
(кроме синего) — значения в шапке `tokens.css`; задаёт их `edColors()` в
`frontend/src/lib/highlight.ts`. Меняя цвет, правьте оба места.

## Быстрые правки

В `tokens.css`, в блоке `:root`:

```css
--accent: #117dff;          /* акцент: тумблеры, ссылки, подсветка */
--accent-dark: #0e63cc;     /* наведение акцентных ссылок */
--primary: #2f6fe0;         /* основные кнопки */
--primary-dark: #2860c8;    /* наведение основной кнопки */
--accent-bg: #e4f0ff;       /* мягкая акцентная поверхность */
--paper: #f9f9f8;          /* фон приложения */
--surface: #ffffff;        /* карточки */
--font-ui: 'Instrument Sans', system-ui, sans-serif;
--font-display: 'Newsreader', serif;
--ui-zoom: 1.06;           /* масштаб оболочки, шапки, тулбаров и окон */
--radius-card: 18px;
--radius-button: 999px;
```

Переопределения для тёмной темы находятся в `.dark`. Меняя акцент, проверяйте обе темы: у них отдельные значения. Новый web-шрифт подключается в `frontend/index.html`; для dev-каталога — также в `frontend/ui-test.html`. Системный шрифт подключения не требует.

`--font-mono` используется одновременно текстовым полем редактора, подсветкой и измерителем прокрутки через `EDITOR_FONT`. Их нельзя настраивать отдельно: строки перестанут совпадать. Шрифты, поля и цвета листа A4 намеренно независимы от темы интерфейса — это оформление экспортируемого документа.

## Использование компонентов

```tsx
import { Button, Card, TextField, Toggle } from '../components/ui'

<Card className="p-6">
  <TextField label="Имя" value={name} onChange={e => setName(e.target.value)} />
  <Toggle label="Номера страниц" on={enabled} onToggle={() => setEnabled(!enabled)} />
  <Button type="submit" variant="primary" busy={saving}>Сохранить</Button>
</Card>
```

`Button`: варианты `primary`, `secondary`, `ghost`, `danger`; размеры `sm`, `md`, `lg`. По умолчанию `type="button"`: отправка формы задаётся явно. `busy` блокирует повторное действие и добавляет индикатор загрузки.

`FieldGroup` объединяет поля общей поверхностью с разделителями. `TextField`, `PasswordField`, `TextAreaField` связывают подпись и подсказку с полем. `IconButton` требует `title`, `Toggle` — `label`, `ModalShell` — `label`. Модальное окно удерживает клавиатурный фокус, закрывается по Escape и возвращает фокус при закрытии.

`SegmentedControl` группирует `SegButton`; активное состояние задаётся через `active`. `Notice` поддерживает `info`, `error`, `warning`. `Card`, `Avatar`, `Badge`, `Brand`, `RangeField` и `SettingRow` покрывают остальные повторяющиеся элементы.

Раскладку задавайте через `className`; цвета, тени и скругления повторяющихся контролов меняйте в общих стилях. Не копируйте CSS кнопки на отдельную страницу.

## Посмотреть и проверить

После `cd frontend && npm run dev` откройте `http://localhost:5173/ui-test.html`. Каталог показывает реальные компоненты и обе темы, позволяет проверить поля, переключатели, состояния кнопок и окно. Он не подключается к API и не входит в production-сборку.

Проверяйте главную и редактор на ширине 375 и 1440 px, в светлой и тёмной теме. После смены моноширинного шрифта проверьте подсветку и позицию каретки в редакторе.
