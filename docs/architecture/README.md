# Устройство приложения

- React + Vite — редактор и превью.
- FastAPI — только экспорт DOCX; аккаунтов и БД нет, документы на сервере не хранятся.
- localStorage — Markdown, настройки и изображения пользователя.
- python-docx и Pandoc — создание DOCX и формул.

Подробности: [конвертер](converter.md), [путь документа](flows/document.md).
Команды — в [AGENTS.md](../../AGENTS.md), причины решений — в [ADR](../decisions/README.md).

Этот раздел меняем, когда меняются обязанности модулей, хранение или передача данных.
Внешнее поведение описываем в specs, а каждую функцию здесь не пересказываем.
