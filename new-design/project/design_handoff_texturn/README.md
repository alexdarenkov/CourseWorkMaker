# Handoff: Texturn — редизайн UI/UX

## Overview
Texturn — веб-редактор для студенческих работ (курсовые, дипломы, рефераты): пишешь в Markdown, справа живое постраничное превью «как в Word» по ГОСТ 7.32-2017, экспорт в DOCX, ИИ-агент строит план и генерирует работу. Этот пакет — редизайн интерфейса: новая палитра, тёмная/светлая тема, единый хедер, экраны «Главная / Создать с ИИ / Редактор / Вход / Профиль», модалки настроек и пополнения баланса.

## About the Design Files
Файл `Texturn App v2.dc.html` — **дизайн-референс, сделанный в HTML** (прототип, показывающий внешний вид и поведение), а НЕ продакшн-код для копирования. Задача — **воссоздать эти экраны в вашем существующем окружении** (проект на React + TypeScript + Vite + Tailwind, см. папку `frontend/`), используя уже принятые в нём паттерны и библиотеки. Вся навигация в прототипе реализована через локальный стейт (переключение `page`), в реальном приложении это `react-router` (уже есть в проекте: `AuthPage`, `CreatePage`, `EditorPage`, `HomePage`).

> Формат `.dc.html` — это просто прототип. Не тащите его в кодовую базу как есть; переносите разметку/стили/логику в существующие React-компоненты.

## Fidelity
**High-fidelity (hifi)** — финальные цвета, типографика, отступы, состояния и микроанимации. UI нужно воссоздать пиксель-в-пиксель средствами вашего стека (Tailwind + существующие компоненты `frontend/src/components/`).

## Design Tokens

Тема переключается атрибутом `data-theme="dark"` на `<html>`. Акцент задаётся CSS-переменными (перекрашивается в рантайме).

### Светлая тема
- `--accent: #117dff` (основной синий — все первичные кнопки)
- `--accent-dark: #0e63cc` (hover первичных кнопок)
- `--accent-bg: #e4f0ff` (мягкая акцентная подложка, чипы)
- `--bg: #faf9f5` (фон страницы), `--surface: #fff`
- `--desk: #eeece3` («стол» под листом A4)
- `--border: #e2dfd2`, `--line: #e8e6dc`, `--hover: #f0eee6`
- `--text: #3d3929`, `--text-2: #6b6553`, `--text-3: #8a8470`
- `--toggle-off: #dcd9cd`, `--overlay: rgba(61,57,41,.42)`
- `--header-bg: rgba(250,249,245,.85)`, `--header-line: #dcd8c8`
- Редактор кода: `--code-bg: #fffefb`, `--bar-bg: #f4f1e9`
- Подсветка синтаксиса: `--sx-dim:#b8b2a0` `--sx-head:var(--accent)` `--sx-fence:#7a7563` `--sx-link:#3e6b8f` `--sx-math:#7c5cbf` `--sx-caption:#5d8a52`

### Тёмная тема
- `--accent-bg: hsl(213 60% 20%)`
- `--bg:#1b1a17`, `--surface:#242320`, `--desk:#151410`
- `--border:#3a372f`, `--line:#33312a`, `--hover:#2a2823`
- `--text:#e6e3d8`, `--text-2:#aaa494`, `--text-3:#948f7e`
- `--toggle-off:#45423a`, `--overlay:rgba(0,0,0,.6)`
- `--header-bg:rgba(27,26,23,.85)`, `--header-line:#3a372f`
- `--code-bg:#201f1c`, `--bar-bg:#201f1c`
- Логотип-бейдж: `--logo-bg`/`--logo-fg` инвертируются (светлый квадрат, тёмная буква)

### Спец-цвета (заданы напрямую, не токенами)
- Кнопка выхода из аккаунта: `#d64435` (hover `#c03729`)
- «Магический» градиент ИИ-кнопок: `linear-gradient(110deg, #3b6fe0 0%, #7b52d6 42%, #d84bb0 78%, #ff7a59 100%)` с тенями `rgba(123,82,214,.18)` / `rgba(216,75,176,.16)`
- Аватар пользователя: спокойный градиент из двух оттенков, вычисляемых по имени (hash → hue, `hsl(hue 72% 62%)` → `hsl(hue+42 68% 54%)`)

### Типографика
- Заголовки/логотип: **Newsreader** (serif), weight 400–600, отрицательный letter-spacing (~-.015em). Логотип — «Texturn» капсом, letter-spacing .22em.
- Интерфейс: **Instrument Sans**, 13–15px.
- Код редактора: **JetBrains Mono**, размер регулируется (12–18px).
- Лист A4 превью: **Times New Roman**, 14pt, полуторный интервал, красная строка, поля по ГОСТ.

### Радиусы, тени
- Кнопки — полностью скруглённые (`border-radius: 999px`, пилюли).
- Карточки/модалки — `border-radius: 18–20px`.
- Тени мягкие двухслойные: `0 1px 2px rgba(61,57,41,.04), 0 10–24px … rgba(61,57,41,.08–.16)`.

## Screens / Views

### 1. Хедер (единый на всех страницах)
Высота 56px, sticky, `backdrop-filter: blur(10px)`, нижняя линия `--header-line`. Слева: логотип «Texturn» (Newsreader) + вертикальный разделитель + nav-кнопки **Редактор** (иконка square-pen) и **Создать с ИИ** (иконка sparkles, фон — градиент ИИ). Активный раздел подсвечен (`--hover` фон, акцентный текст). Справа: переключатель темы (солнце/луна), затем либо кнопка **Войти** (если не авторизован — иконка анонима), либо аватар с инициалами (ведёт в профиль).

### 2. Главная
Hero-грид 2 колонки (на десктопе `.82fr / 1.18fr`, ≤920px — одна колонка). Слева: верхний лейбл капсом («ГОСТ 7.32—2017 · автоматически»), крупный serif-заголовок, описание, две кнопки одинакового размера («Создать с ИИ» — градиент; «В редактор» — вторичная с обводкой), строка фич с точками-маркерами над тонкой линией. Справа: макет окна редактора в стиле macOS (traffic-lights, две панели — Markdown-код с подсветкой + лист A4 с формулой/таблицей/графиком).

### 3. Создать с ИИ (`/create`)
На всю высоту окна (`100vh - 56px`), 2 равные колонки с вертикальной линией.
- **Слева — параметры генерации** (скроллится): 2 инпута (Название работы, Основные требования — с кнопкой-скрепкой прикрепления файла внутри, фон меняется при фокусе, бордер не меняется), тиры качества (Быстро/Баланс/Качество — активный `--hover`), слайдер объёма (5–40 стр), тумблеры (таблицы, схемы, формулы, графики, приложение с кодом).
- **Справа — план работы** (скроллится отдельно): если план не построен — пустое состояние + кнопка **Создать план** (градиент). После построения — список разделов, у каждого редактируемые название и описание (нельзя перемещать), кнопка удаления, «Добавить раздел». Внизу за линией — кнопка **Сгенерировать работу** (градиент). Любое изменение параметров слева сбрасывает план обратно в пустое состояние.

### 4. Редактор
Хедер + сплит `editor | ручка-ресайз | preview`. Кнопка **Скачать .docx** в хедере.
- **Панель редактора**: тулбар (иконка «Загрузить .md/.zip» слева за разделителем, затем вставка изображения/таблицы/кода/схемы/формулы, шестерёнка — открывает «Настройки редактора»), номера строк, подсветка синтаксиса JetBrains Mono, снизу — ИИ-консоль (поле «Что изменить?» + круглая кнопка отправки с градиентом).
- **Ручка-ресайз**: тянется, при достижении ~20% ширины правая панель сворачивается; появляется язычок-стрелка (в стиле iOS), выступающий за границу, — растягивается вправо при наведении на шторку и открывает панель обратно.
- **Панель превью**: тулбар (зум −/%/+, развернуть, шестерёнка — «Настройки документа»), «стол» и лист A4 (Times New Roman, формула с номером «(1)» справа, абзац «где …», SVG-график, подпись «Рисунок 1 – …»). Лист A4 всегда белый в любой теме.

### 5. Вход / Регистрация
Центрированная карточка. Логотип «Texturn» (Newsreader) сверху. Сегмент-переключатель Вход/Регистрация (активный сегмент `--seg-active`). Поля (в регистрации добавляется имя), первичная кнопка входа с иконкой log-in. Ссылка «Продолжить как гость». Вход выставляет статус «авторизован» и ведёт в редактор.

### 6. Профиль
Хедер + `<main>` (max 960px). Карточка **информации о пользователе**: аватар с градиентом + имя + email, кнопки **Изменить** и **Выйти** (красная) в шапке карточки. Режим редактирования — только поле «Имя» (Сохранить/Отмена). Карточка **Баланс**: слева лейбл + сумма в ₽ (Newsreader), справа синяя кнопка **Пополнить**, снизу за линией — «Списывается только за реальную генерацию — без ежемесячных платежей». Иконка кошелька в нейтральных серых тонах.

### Модалка «Пополнить баланс»
Оверлей + blur. Пресеты сумм (200–5000 ₽) + поле произвольной суммы, синяя кнопка «Пополнить на N ₽». Без тарифов/подписки — деньги тратятся на ИИ-токены (модели разные, цена не указывается).

### Модалка «Настройки»
Две секции (открываются из шестерёнок редактора/превью):
- **Настройки редактора**: слайдер размера шрифта (12–18, стиль `tx-range`), тумблеры (подсветка синтаксиса, перенос строк, номера строк).
- **Настройки документа**: тумблеры (титульный лист, содержание, нумерация страниц, нумерация рисунков/таблиц/формул).
Тумблеры — приплюснутые пилюли (дорожка 36×16, ползунок 20×12, светлый). У последнего пункта нет нижней линии.

## Interactions & Behavior
- Навигация: клики по хедеру/кнопкам меняют экран. В реальном приложении — роуты.
- Тема: тумблер в хедере переключает `data-theme`, плавный `transition: background .25s`.
- План на `/create` инвалидируется при любом изменении параметров слева.
- Ресайз-шторка редактора: drag меняет ширину, порог сворачивания ~20%, язычок открывает обратно.
- Модалки закрываются по клику на оверлей, крестику и кнопке действия.
- Микроанимации: `tx-rise` (появление снизу), `tx-pop` (модалки), `tx-grow` (столбцы графика), `tx-caret` (мигающий курсор). Кнопки — hover без «прыжка» у части (только `filter: brightness`), у части — `translateY(-1px)`.

## State Management
- `page` (текущий экран) — заменить на router.
- `dark`, `hue` (тема/акцент).
- `/create`: `topic`, `reqs`, `quality`, `pages`, `opts{}` (тумблеры), `plan[]` (разделы {title, desc}), `planBuilt` (флаг).
- Профиль: `profile{name,email}`, `editing`, `draft`, `balance`.
- Модалки: `settingsOpen`+`settingsSection`, `pricingOpen`, `topupChoice`/`customAmount`.
- Настройки: `edFont`, `edOpts{}`, `docOpts{}`.
- Авторизация: `authed`.
